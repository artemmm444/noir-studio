# NOIR® — креативная студия

Демо-работа для портфолио. Тип: сайт студии/агентства. Направление: editorial, типографика-первая.

## Дизайн
- Шрифты: Unbounded (дисплей, кириллица), Onest (текст), JetBrains Mono (метки)
- Палитра: чернильный #0f0f10 / кость #e8e3d9 / ультрамарин #2b3bea
- Инверсия секций: тёмная → светлая «бумажная» секция индекса работ
- Зерно-оверлей, контурный текст (text-stroke), острые углы, hairline-линии

## Интерактив
- Прелоадер-счётчик 000→100
- Живые часы (Москва) в хедере
- Hero: строки въезжают с задержкой
- Индекс работ: превью-карточка следует за курсором
- Анимированные счётчики, scroll-reveal
- Полноэкранное меню на мобилке, `prefers-reduced-motion`

## Стек
Чистый HTML + CSS + vanilla JS. Без фреймворков.

## Запуск
Открыть `index.html` двойным кликом.
